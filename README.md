# getcoraly.app

Marketing site for [Coraly](https://apps.apple.com/app/id6778913380), the private blood pressure log.

Static, dependency-free: two HTML pages, a few images, no build step. Hosted on GitHub Pages.

The privacy policy lives at `privacy/index.html` (https://getcoraly.app/privacy/). The old coraly-privacy-policy repo still serves its own copy until the app switches to the new address (planned for 1.4.0); after that it becomes a redirect here and must stay published, because app versions 1.0 to 1.3.1 link to its URL.
